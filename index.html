Enable remindersWhile the app is open

On iPhone, browser reminders can only be delivered while this app is open. Reliable scheduled or push notifications require an installed web app, notification permission, a push service, and a server. This build has no push server.

Install on iPhone

PWA

1. Open the hosted app link in Safari.
2. Tap Share, then Add to Home Screen.
3. Open il9aBody from your Home Screen.

The app must be served over HTTPS for installation and offline caching. Opening the HTML file directly will not enable PWA features.
